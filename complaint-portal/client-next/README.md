# APTHEX Complaint Portal — Next.js frontend

This is the canonical frontend for the public complaint portal and the staff Case Desk.

Use the workspace commands from the repository root (`complaint-portal/`):

```bash
npm run dev        # API + frontend
npm run build      # production build
```

See the root `README.md`, `API.md`, and `TEST_REPORT.md` for setup, API contracts, and test results. The legacy Vite app in `../client/` is not used.
